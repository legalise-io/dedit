# Dedit 0.2.6 / docx2tiptap 0.2.2

Release prepared 2026-10-01.

- Fix tracked editing across multiple steps, multi-block paste and remote Yjs updates.
- Preserve paragraph identity and direct formatting through structural edits.
- Fix comment anchors, blank paragraphs, raw formatting reconciliation and table heading revisions in DOCX conversion.
- Insert AI-generated text literally and preserve whitespace when computing edits.
- Fix editor/readOnly updates, collaboration document lifecycle, AI listeners, prompt commands and numbering limits.
- Prevent collaboration persistence filename collisions; retain reads of legacy safe filenames.
- Add 193 tests, independent 70% coverage gates and CI. See [the review](../reviews/2026-10-01-dedit.md) and [test instructions](../TESTING.md).
- Fix CommonJS external dependency interoperability and check both package entry points before release.
- Export the shared extension factory and preserve tracked tabs from the existing integration work.

The converter now requires python-docx >=1.2.0 for comment export. New imports preserve paragraph properties by stable IDs; old index-only payloads remain readable. Ambiguous legacy collaboration filenames need manual migration. Existing TipTap 2 and development-tool advisories remain documented in the review.

Fredit consumers must refresh their dependency artifacts and reconcile their separate track-changes patch with the revised upstream code.
